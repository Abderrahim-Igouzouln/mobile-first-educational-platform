useState : gérer l'état local d'un composant

Le Hook useState est l'un des Hooks fondamentaux de React. Il permet d'ajouter de la réactivité à tes composants : chaque fois que l'état change, React re-rend automatiquement le composant. 

import { useState } from 'react'

function Compteur() {
  const [count, setCount] = useState(0)

  return (
    <div>
      <p>Valeur : {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Incrémenter
      </button>
    </div>
  )
}

💡 À retenir : useState retourne un tableau de deux éléments : la valeur actuelle et une fonction pour la modifier. Ne modifie jamais l'état directement — toujours passer par la fonction setter.
