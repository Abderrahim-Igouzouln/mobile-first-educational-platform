# Security Policy — DevEduForge

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability in DevEduForge,
please report it privately via email at **security@deveduforge.ma**.

**Do not** disclose the vulnerability publicly via GitHub issues or pull requests
before we have had a reasonable opportunity to address it.

We aim to acknowledge receipt of vulnerability reports within 48 hours and
provide a detailed response within 5 business days.

## Disclosure Policy

- We will acknowledge receipt of your report
- We will investigate and determine impact
- We will release a fix as soon as possible
- We will publicly disclose the issue after the fix is deployed

Thank you for helping keep DevEduForge and its users safe.
