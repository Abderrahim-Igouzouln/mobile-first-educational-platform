# Changelog

## [1.0.0] - 2026-06-21

### Added
- Initial release of DevEduForge Backend
- Authentication system (register, login, JWT refresh rotation, email verification)
- User management (profile, preferences, account deletion)
- Course management (domains, technologies, courses, lessons, bookmarks)
- Exercise system (QCM, True/False, Fill-blank with server-side correction)
- Project submission & review workflow
- Certification generation (PDF + HMAC-signed QR code)
- Subscription & payment (Stripe + CMI providers)
- Progress tracking (streaks, achievements, activity feed)
- Notification system (push, email, in-app)
- Analytics & community features
- Offline sync (delta sync, conflict resolution)
- Admin panel & audit logging
